Git Command List

Git Configuration

  • git config --global user.name "Ronin" - set Git username.
  • git config --global user.email "your@email.com" - set Git email.

SSH Setup

  • ssh-keygen -t ed25519 -C "your@email.com" - generate a new SSH key.
  • ssh -T git@github.com - test GitHub SSH connection.

Repository Initialization

  • git init - initialize a new Git repository.
  • git status - show repository status.

Creating Commits

  • git add Resume - add Resume project to staging.
  • git commit -m "Add Resume homework" - create Resume commit.
  • git add Greenshop - add Greenshop project to staging.
  • git commit -m "Add Greenshop homework" - create Greenshop commit.
  • git log --oneline - show commit history.

Working with Remote Repository

  • git remote add origin git@github.com:ronin-frontend/frontend-homework.git - connect local repository to GitHub.
  • git remote -v - show remote repository.
  • git pull origin main --allow-unrelated-histories - merge local and remote repositories.
  • git push -u origin main - upload commits to GitHub.

Working with Branches

  • git switch -c homework-4 - create and switch to the homework branch.
  • git branch - show all branches.
  • git push -u origin homework-4 - upload the homework branch to GitHub.
